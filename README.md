# BLOCKSTRIKE

A Krunker-style 3D arena FPS that runs in the browser (three.js, no build step).

Run: `python3 -m http.server 8000` then open http://localhost:8000/index.html (or just open `index.html`).

Controls: WASD move, Shift sprint, Space jump (hold to bunny-hop), C/Ctrl crouch (sprint + crouch = slide),
Mouse1 shoot, Mouse2 aim, R reload, 1/2/3 or wheel switch weapon.
